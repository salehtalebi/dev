🔐 Authentication (تایید هویت)

POST /wp-json/jwt-auth/v1/token
دریافت JWT Token برای احراز هویت

Parameters:

پارامتر نوع ضروری توضیحات
username string بله نام کاربری یا ایمیل
password string بله رمز عبور

Request Example:

{ "username": "admin@academy.com", "password": "your_password" }

Response Example:

{ "token": "eyJ0eXAiOiJKV1QiLCJhbGciOiJIUzI1NiJ9...", "user_email": "admin@academy.com", "user_nicename": "admin", "user_display_name": "مدیر سیستم", "user": { "id": 1, "username": "admin", "email": "admin@academy.com", "first_name": "مدیر", "last_name": "سیستم", "roles": ["administrator"], "is_account_manager": true } }
نکته: فقط کاربران با نقش Administrator یا Shop Manager می‌توانند توکن دریافت کنند.
POST /wp-json/jwt-auth/v1/token/validate
تایید اعتبار JWT Token

Headers:

Authorization: Bearer YOUR_JWT_TOKEN

Response (Valid Token):

{ "code": "jwt_auth_valid_token", "data": { "status": 200 } }

📦 WooCommerce Orders API

GET /wp-json/wc/v3/orders
دریافت لیست سفارشات

Query Parameters:

پارامتر نوع ضروری توضیحات
page integer خیر شماره صفحه (پیش‌فرض: 1)
per_page integer خیر تعداد آیتم در صفحه (حداکثر: 100)
status string خیر وضعیت سفارش (pending, processing, completed, etc.)
customer integer خیر ID مشتری
after string خیر سفارشات بعد از تاریخ (ISO8601)
before string خیر سفارشات قبل از تاریخ (ISO8601)

Headers:

Authorization: Bearer YOUR_JWT_TOKEN

Frontend Implementation:

// در فایل src/stores/orders.js const response = await ordersAPI.getOrders({ page: 1, per_page: 20, status: 'completed' })
GET /wp-json/wc/v3/orders/{id}
دریافت جزئیات یک سفارش

Path Parameters:

پارامتر نوع ضروری توضیحات
id integer بله شناسه سفارش

Frontend Implementation:

// در فایل src/pages/order-detail.vue const order = await ordersStore.fetchOrder(orderId)
PUT /wp-json/wc/v3/orders/{id}
بروزرسانی وضعیت سفارش

Request Body:

{ "status": "completed" }

Frontend Implementation:

// در فایل src/pages/order-detail.vue await ordersStore.updateOrderStatus(orderId, 'completed')

📤 Export API

GET /wp-json/sales-dashboard/v1/export/orders
خروجی Excel/CSV سفارشات

Query Parameters:

پارامتر نوع ضروری توضیحات
format string خیر فرمت خروجی (csv, excel)
status string خیر فیلتر وضعیت
date_from string خیر از تاریخ
date_to string خیر تا تاریخ
manager_id integer خیر Account Manager ID

Frontend Implementation:

// در فایل src/pages/orders.vue const exportOrders = async () => { const blob = await exportAPI.exportOrders({ format: 'excel', status: 'completed', date_from: '2024-01-01', date_to: '2024-12-31' }) // دانلود فایل const url = window.URL.createObjectURL(blob) const a = document.createElement('a') a.href = url a.download = 'orders-export.xlsx' document.body.appendChild(a) a.click() window.URL.revokeObjectURL(url) }
GET /wp-json/sales-dashboard/v1/export/customers
خروجی Excel/CSV مشتریان

Frontend Implementation:

// در فایل src/pages/customers.vue const exportCustomers = async () => { const blob = await exportAPI.exportCustomers({ format: 'excel', manager_id: selectedManagerId }) // ... دانلود مشابه بالا }

🖥️ Frontend Usage Examples

🔗 API Service Configuration

// فایل src/services/api.js import axios from 'axios' const API_BASE_URL = import.meta.env.VITE_API_BASE_URL || 'https://academy.com' const WC_API_BASE = `${API_BASE_URL}/wp-json/wc/v3` const CUSTOM_API_BASE = `${API_BASE_URL}/wp-json/sales-dashboard/v1` const apiClient = axios.create({ timeout: 10000, headers: { 'Content-Type': 'application/json', } }) // Add JWT token to requests apiClient.interceptors.request.use( (config) => { const token = localStorage.getItem('wp_token') if (token) { config.headers.Authorization = `Bearer ${token}` } return config } )

🔐 Authentication Store Usage

// فایل src/pages/login.vue import { useAuthStore } from '@/stores/auth' const authStore = useAuthStore() const handleLogin = async () => { const result = await authStore.login({ username: form.value.email, password: form.value.password }) if (result.success && authStore.isAdmin) { router.push('/dashboard') } }

📦 Orders Management

// فایل src/stores/orders.js import { ordersAPI } from '@/services/api' export const useOrdersStore = defineStore('orders', () => { const orders = ref([]) const filters = ref({ status: '', account_manager: '', date_from: '', date_to: '' }) const fetchOrders = async () => { const response = await ordersAPI.getOrders({ page: currentPage.value, per_page: 20, ...filters.value }) orders.value = response.data } return { orders, filters, fetchOrders } })

👥 Customers Management

// فایل src/pages/customers.vue import { useCustomersStore } from '@/stores/customers' const customersStore = useCustomersStore() // فیلتر بر اساس Account Manager const filterByManager = async (managerId) => { customersStore.setFilters({ account_manager: managerId }) await customersStore.fetchCustomers() } // مشاهده جزئیات مشتری const viewCustomer = (customerId) => { router.push(`/customers/${customerId}`) }

📊 Dashboard Analytics

// فایل src/pages/dashboard.vue import { useDashboardStore } from '@/stores/dashboard' const dashboardStore = useDashboardStore() onMounted(async () => { await dashboardStore.fetchDashboardData() // Setup charts with real data setupSalesChart(dashboardStore.salesData) setupTopProductsChart(dashboardStore.topProducts) })

📤 Export Functionality

// Export with current filters const exportWithFilters = async () => { try { isExporting.value = true const blob = await exportAPI.exportOrders({ format: 'excel', ...ordersStore.filters // Apply current filters }) // Download file const url = window.URL.createObjectURL(blob) const a = document.createElement('a') a.href = url a.download = `orders-${new Date().toISOString().split('T')[0]}.xlsx` document.body.appendChild(a) a.click() window.URL.revokeObjectURL(url) } catch (error) { console.error('Export error:', error) } finally { isExporting.value = false } }

📡 HTTP Status Codes

200 - موفق
400 - خطای درخواست
401 - غیر مجاز
403 - دسترسی ممنوع
404 - یافت نشد
500 - خطای سرور
